# Hays-Botany-Public

**Status (October 28, 2026): proposed collection hub; NOT the live Hays Botany public website, not a production catalog, and not an approved routing cutover.**

The current authoritative botanical source and live public Visual Learner remain at [Crking92/Hays-County-Botany](https://github.com/Crking92/Hays-County-Botany) and [its existing Pages site](https://crking92.github.io/Hays-County-Botany/).

The intended Option B architecture is ten separate family/group learner sites with a coherent shared appearance, connected through a future hub. This repository is intended for the hub-wide species search, family navigation, glossary, quiz, and fallback paths; it does not own canonical species/photo curation simply because it is a public repository.
